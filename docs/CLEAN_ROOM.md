# Clean-room 独立开发声明

> 本文件是仓库级的开发边界契约。任何贡献者（包括 AI Agent）在提交代码前必须先读本文件。
> 最后更新：2026-11-10

## 1. 本项目是什么

MeetingStone（集合石）是一个面向 DeepSeek Harness（DSH）的**全新独立开源插件**，为 DSH 增加跨 CLI 的智能体角色映射与按角色派单能力。

## 2. 绝对禁止的来源

本项目**不得**复制、改编、引入或以任何形式依赖 **CLIWorker**（含 `dsh-cliworker-now`、`CLIWorker Now` 以及其任何历史版本）的实现：

- ❌ 不复制其源代码、函数、模块、代码片段、补丁或测试代码
- ❌ 不 Fork 后改名或改造为本项目
- ❌ 不将其作为安装、运行、构建或升级依赖
- ❌ 不复制其数据结构、接口定义、配置 schema、UI 结构

## 3. 允许的参考范围

以下内容**可以**参考，因为它们属于需求与行为层面，而非实现层面：

- ✅ 功能需求、用户交互流程、产品形态
- ✅ 历史 Bug、运行问题、已知坑（用于避坑，不用于照抄修复代码）
- ✅ 公开的第三方文档、DSH 官方文档与官方源码
- ✅ 各 CLI 厂商的官方文档与协议说明
- ✅ 通用编程知识、社区公开知识

## 4. 开发期使用 CLIWorker 的边界

开发期允许使用本机安装的 CLIWorker 作为**派发工具**，把开发任务交给 Codex / CodeBuddy 等外部 CLI 执行。这属于「用工具」，不属于「抄实现」：

- ✅ 允许：用 CLIWorker 启动 Worker、读其运行结果
- ❌ 禁止：把 CLIWorker 的返回值/内部格式当作产品设计依据去反向模仿其实现
- ❌ 禁止：在产品代码或依赖中引用 CLIWorker

此类用法必须在提交说明中可追溯。

## 5. 来源审查流程

| 阶段 | 要求 |
| --- | --- |
| 提交前 | 自查：是否有任何代码/结构来自第 2 节禁止来源 |
| 评审时 | 评审者（悟空/唐僧）对新增文件做一次来源质疑，回答"这段是怎么来的" |
| 发布前 | 全仓库做一次来源扫描（关键词 + 目录 + 依赖树），结果记录进 `docs/security.md` |

## 6. 与 DSH 的关系

- 本项目是 DSH 的**第三方插件**，复用 DSH 官方能力，不修改 DSH 核心代码，不维护 DSH 私有分支。
- 在获得官方明确收录/认证前，任何文档不得使用"官方插件""官方认证"等表述。
- 本项目与各模型/CLI 厂商无隶属或背书关系，README 必须声明。
