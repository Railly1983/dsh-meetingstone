## 2. CHANGELOG 条目（0.0.x → 0.1.0-alpha）

`CHANGELOG.md` 的 0.0.5–0.0.16 从未单独记条目，0.1.0-alpha 是这条开发线的**汇总条目**。
发布时把下面草稿粘到 `[Unreleased]` 之前，按实际内容删改，**不要留未发生的承诺**：

```markdown
## [0.1.0-alpha] - 2026-11-11

首个公开预发布版本（0.0.x 开发线汇总）。外部 CLI 派单仍需自行安装官方 provider bundle。

### Added
- 协作效率 P0：`get_task` 默认返回结构化摘要（全文用 `full:true` / `get_run_artifact` 按范围读）；
  `list_roles` 紧凑视图；`dispatch` 支持 TaskSpec / ContextPack 结构化简报与输出契约；
  `meetingstone_wait` 一次等待多个任务，不轮询；`continuesFrom` 作为协议内可选字段，不单列卖点。
- 原生 Jobs：派单注册 `meetingstone-dispatch` Job（角色 · 通道 · 摘要），取消优先走 `ctx.jobs.kill`；
  Jobs 不可用时只告警，派单继续。
- 并行多任务：默认每任务独立 git 工作树（`isolation: worktree`），建树失败即拒绝派单；
  同项目改动交集以 `overlapWarnings` 提示；工作树/分支不自动删除。
- 进行中重复任务去重：多因素指纹，命中返回既有 `taskRef`；仅内存索引，终态清理。
- 失败快分类：`failureClass` + `hint`（quota / auth / permission / timeout / network / refusal / crash / unknown），不自动重试。
- GUI：设置页「集合石」只读 section（角色 / 通道 / 最近错误），经 Typert Remote 读宿主同一份数据。
- 通道：Codex、CodeBuddy(ACP)、Claude Code、in-process；本机 CLI 多源探测（PATH / Appx / npm / 常见目录）。
- 配置：global → project → session 三级覆盖（只存差异）；项目级 `.meetingstone.json`。
- 结果落盘：`.meetingstone/runs/<childId>.json`，原子写、256 KiB 上限、100 条 / 30 天，跨重启可查。

### Changed
- 版本线 0.0.x → 0.1.0-alpha。

### Removed
- 只读通道整体移除（宿主 subagent spec 无权限字段）；项目级 `limits` 死配置移除。

### Security
- 派单 `cwd` 必须落在项目根内；工作树建树前后 realpath 校验；不读取或注入任何 CLI 凭据。
```

核对：条目须覆盖 **P0 效率机制 / Jobs / GUI / Claude·CodeBuddy·Codex 通道** 四类；
日期用实际发布日期，不能写「待定」。

| 冒烟项 | 步骤 | 通过标准 |
| --- | --- | --- |

## 7. 已知限制（发布说明必须同步）

- **Jobs 是进程内的**：Job 只在当前 DSH 进程注册；进程退出/重启后旧 Job 不续跑、不再出现在面板。
  插件卸载会把存活任务写 `interrupted`。宿主未加载 `@deepseek-ai/dsh-tool-jobs` 时不建 Job，只告警。
- **去重仅内存**：进行中任务指纹索引只存在当前插件实例；重启、跨进程、跨 profile 都不共享。
- **非 git 项目不去重**：版本指纹依赖 `git rev-parse HEAD`，取不到版本时按「信息不足」新建任务，
  宁可重复也不误合。
- **GUI 未真机验证项**：设置页 section 的真实渲染、`Tag`/主题 token、`ctx.remote.$mount` 与 Typert
  Gateway 传输只有 stub harness；项目级 `.meetingstone.json` 覆盖在设置页不可见；页面无自动刷新；
  `lastError` 只存进程内最近一条。宿主缺 Typert 时页面显示读取失败，不显示假数据。
- **Codex 额度与模型**：官方 provider 自带 Codex `0.153.4`，可用模型受账号限制；额度耗尽归为
  `quota`，插件不自动重试、不换模型。换 0.167 需按 [installation.md](../installation.md) 手动镜像。
- **Claude Code 通道未真机验证**：本机未安装 Claude CLI，provider 自带 CLI 的派单未实测；
  当前示例配置里该角色默认 `enabled: false`。
- **平台**：只在 Windows 11 + DSH `0.2.2-rc.1` 上验证；`engines.dsh` 要求 `>=0.2.2-rc.1 <0.3.0-0`。
- **不提供只读通道**；工作树隔离是文件布局隔离，**不是权限沙箱**（[security.md](../security.md)）。
- npm / GitHub Release 链路本身**尚未实测**（本清单只写步骤）。
