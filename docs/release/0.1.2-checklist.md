# 0.1.2 发布清单

> 目标版本：`0.1.2`
> 范围：路由忠实性（F1）与可用性口径（F2）修复，经独立外部审查三轮复核通过。
> 相对 `0.1.1` 无破坏性变更。

## 0. 本次变更

| 项 | 内容 |
| --- | --- |
| 修复 F1 | 非进程内 provider 声明模型与实际执行不一致（声明 B 静默跑 A）→ 启动前核对并拒绝；补实例/角色 CLI/模型/强度一致性与合并顺序，堵住三条绕过路径 |
| 修复 F2 | `roleAvailability` 与真实派单双口径 → 三处共用 `resolveRoleRoute`（`src/dsh/route.js`） |
| 变更 | 恢复老版本 channels 能力匹配；移除 provider 克隆/派生机制 |
| 变更 | 能力探测改用官方只读 RPC，不再消耗额度；额度耗尽标 `blocked=rate-limit` |
| 变更 | 角色颜色只跟开关走；`refreshCli` 超时保护 + 分段耗时日志 |
| 清理 | 移除 `src/dsh/provider-assembler.js` 及死代码/过时注释/测试 |
