## 0. 本次变更

| 项 | 内容 |
| --- | --- |
| 新增 | 内置 3 个默认角色（`role-worker` / `role-reviewer` / `role-researcher`），走 DSH 原生子 Agent，不绑定外部 CLI / 模型 |
| 新增 | `src/roles/defaults.js`：默认角色只在用户**没有任何角色**时生效，不覆盖已有配置，只在内存注入不写盘 |
| 修复 | 编辑/删除默认角色时写路径报 `ROLE_NOT_FOUND`（看得见却改不了）→ 写前先物化 |
| 修复 | 公开仓库 CI 全红：测试依赖 `zod` 但 CI 从不安装依赖 → 加 `npm install` + 改用 `npm test` |
| 修复 | 发布门禁 D1 是绑定维护者私有 profile 的伪测试 → 改为生产模块契约断言 + 负对照 |
| 文档 | README 中/英重写；新增快速开始（中/英）、场景、FAQ；安装/配置重写，旧配置归档 |
| 清理 | 移除仓库根 `.meetingstone.json`（维护者个人分工）与 `personas.json`（零引用） |
| 清理 | 移除 README 中「48 格对照实验」引用（样本不足，不足以代表真实使用） |
