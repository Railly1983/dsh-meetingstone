## 0. 结论（先给判断）

1. **顺序现状与 C1 §1.4 完全一致**：L1 人设 → L2 TaskSpec 简报 → L3 交接重放 → 本次任务 → 输出契约。C1 §9 D6 明确「作为 C2 基线，**禁止调换**」→ C2 不重排，只做**断言固化 + 量化 + 复用判据**。
2. **稳定前缀只有 L1**（人设 + `你是「role」。`）。合成样本中 L1=2,226 B，首轮提示词合计 4,096 B；L2 起全部随任务变化。
3. **稳定尾段（输出契约）不可前缀缓存**：契约文本按 `artifactPolicy` 稳定（847 B / 906 B），但按 C1 要求固定在末尾 → 只能被 provider 的整段缓存覆盖，不享受前缀缓存。属设计取舍，C2 不改。
4. **动态大头是 L3 交接块**：8KB 上一轮输出 → 10,300 B 重放块（约为首轮 4,096 B 的 2.5×），有界 ≤16KiB。它是同任务多轮时 token 成本的主要变量。
5. **当前没有真正的会话/进程复用**：每次派单都新建 activation；外部 CLI（codex/acp）每次全新会话，provider 未开放续接接口（`src/context-replay.js:3-8`）。C1 允许的「续轮」= continuation 文本重放，不是真续聊。
6. **量化口径**：tool 回执与 runs 字节是真实测量；prompt token 为**估算**（bytes/4 与 CJK 计数取大）；**Provider Usage 一律未知**，不编造节省比例。基线用途是 C2 开工后的对照起点，不是收益声明。

## 5. 「同任务复用会话 / 何时新建」判据草案（未实现，供 C2 裁决）

> 术语：本仓库语境下「复用」= **上下文复用**（`continuesFrom` + `formatContinuation` 重放）；**不是**进程/会话续聊（R5：当前通道不可达）。
> 当前实现：MeetingStone 无自动复用逻辑，复不复用完全由调用方是否传 `continuesFrom` 决定（`src/context-replay.js:354-382`）。

**复用（传 `continuesFrom`）——需全部满足：**

1. 同一任务谱系：同一 `taskId`（C1 新增字段，C3 落地）或同一目标/验收；
2. 同一执行组合：roleId + CLI + 模型 + 思考强度一致（B2 后以编辑器保存值为准）；
3. 同一项目根与隔离方式（`projectRoot`/`isolation` 不变）；
4. 上一轮已终态且不是「需要重来」的失败（`failed/cancelled/interrupted` 默认不复用）；
5. 链长受限：只带**最近一轮**；建议最大链长 ≤3 轮（草案，未验证）；
6. 预算受限：`continuationBytes ≤ 16KiB`（硬上限），且提示词总字节在任务预算内；
7. 保护字段（acceptance/scope/doNotRepeat/permissions/safetyPolicy/artifactPolicy）必须保留（重放器已保证）。

**新建（不传 `continuesFrom`）——任一命中：**

1. 目标/验收变化，或换任务；
2. CLI/模型/强度/通道变化；
3. 隔离方式或工作区变化（worktree ↔ none）；
4. 上一轮失败/取消/中断且需重做，或上次输出不可信到不能作为上下文；
5. 链式重放超过预算（>16KiB 或 >3 轮）；
6. 用户/主控显式要求新上下文；
7. 跨项目。

**记录与可验证点**（C1 §6/§10）：`run.upstreamChildId` + `continuationBytes` + `taskId`；C2 测试断言「无 `continuesFrom` 时无 `[PREVIOUS TASK OUTPUT` 边界」「有则恰好一对」「提示词不含 messages/chatHistory」「执行参数不出现在提示词」。**真实 token 节省：未知**（需 C2 后用同任务 A/B 实测，当前无数据，不编造）。
