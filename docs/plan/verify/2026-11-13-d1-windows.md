### 2.7 三色语义（灰/黄/绿，不引入红） — ⚠️ 部分通过

#### 派生逻辑 ✅ 且可穷举

`src/gui/state-model.js:264-273`：

```js
export function deriveRoleColor({ userPreference, readiness, quota } = {}) {
  if (userPreference === DISABLED || readiness !== READY) return GRAY
  if (quota === EXHAUSTED) return YELLOW
  if (quota === AVAILABLE || UNKNOWN || NOT_APPLICABLE) return GREEN
  return GRAY
}
```

36 种组合穷举：**只产生 gray / green / yellow 三种**，`colorMatrixInvalid: []`，无红色、无第四色。

#### Switch 只在三色间取色 ✅

`Switch`（`:742-794`）的轨道色：

| 入参 color | 轨道 token | 语义 |
| --- | --- | --- |
| `green` | `--dsw-alias-state-success-primary` | 启用正常/未知 |
| `yellow` | `--dsw-alias-state-warn-primary` | 额度耗尽 |
| `gray` / 其他 | `--dsw-alias-label-tertiary` | 关闭/阻断 |
| `checked=false` | `--dsw-alias-border-l4` | 关 |

`switchHasErrorToken: false`、`switchNeverRed: true` —— **开关本身不引入红色**。

真实数据开关实测（含人工构造的黄/灰态）：

```
绿(ready+quota unknown) → aria-checked true,  track state-success-primary
黄(ready+quota exhausted) → aria-checked true, track state-warn-primary
灰(disabled)             → aria-checked false, track border-l4
```

#### 两个问题：黄色生产不可达 + 删除按钮用红

**D1-M3（非阻塞，设计缺口）黄色在生产路径不可达**：

`src/gui/host.js:156-160` 调 `deriveRoleView` 时只传 `{ subagents, availability, sources }`，**没有 `quota` / `quotaSource`**：

```
Claude                 → gray
colorsSeenInProduction: ["green", "gray"]     ← 全程无 yellow
```

**D1-M2（非阻塞，但违反验收口径）删除角色按钮使用红色**：

## 五、是否阻塞发布

### 结论：**建议阻塞发布（alpha.6 不应作为 D1 通过版本对外）**

理由：

1. **D1-B1 是用户可复现的功能性 bug**，且正好命中用户上一轮反馈的第 3、4 个问题（「模型不刷新」「思考强度不可用」）的**同类残留**：`dsh` 这个 CLI 上模型永远为空、「刷新能力」必然报错。这不是边角场景——八戒就是本机默认的调度角色，用户点开就能撞上。
   - 修复成本低（两处枚举各加 1 个值 + 目录读 `llmModel` 回退），但**当前状态下不能宣称「选 CLI 后模型有值」已修复**。

2. **D1-B2 直接违反 D1 的作废项要求**，且属于「删了功能但没删文案」这类最容易让用户困惑的问题——界面指引用户去一个不存在的面板。虽然不影响功能，但**D1 的验收口径明确要求「用户可见文案无通道/不残留会话概念」**，当前 5 处命中，应视为不通过。

3. **U1–U10 全部未完成目视确认**。契约层通过不能替代真机点击：
   - 开关「即时生效」只验证到 `updateGlobalRole` 入参层面，真实 profile 写入 + HMR 生效未验证；
   - 「刷新能力」真实网关往返未跑（我用 strict spec 模拟校验，非真实 HTTP 往返）；
   - 二次确认的实际交互表现（是否真弹、是否可取消）未目视。

4. 各 CLI 的描述、模型、强度、来源都验证到了 JSON/渲染树层面，**这部分可以确认是好的**：4 CLI 选项、单一「角色设定」、来源四档、不支持置灰、返回按钮、三色派生、B3 三个 remote 已删干净、仅注册 settings.section。
