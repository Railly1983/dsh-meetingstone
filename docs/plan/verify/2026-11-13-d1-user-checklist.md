# D1 用户配合清单（10 项，人眼确认，alpha.6 / B3 口径）

> 用途：D1 真机验收里**只有人眼能确认**的部分。你不需要判断代码，也不改任何设置——只需要按步骤点、看、截图，然后把结果（通过/失败+截图）回给 Lead。
> 前置：DSH 已由 Lead 安装 `0.1.0-alpha.6` 并重启（当前正在运行，别关它）。GUI 地址以重启后为准（本轮 Lead 报 `http://127.0.0.1:6257`）。
> 截图方法：`Win + Shift + S` 框选 → 粘贴到画图/微信保存；或 `Win + PrtSc`。每项截 1 张，文件名带编号（如 `U3-保存后.png`）。截图存 `docs/plan/verify/`。
> 提示：界面位置可能与我描述略有差异，按**名称**找即可；找不到入口 = 该项记「失败」并截图，不要自己改配置。
> **B3 重大变化**：会话级角色配置已彻底删除；角色入口从对话页/右侧栏移除；全局角色只在设置页管理。U9/U10 是「作废项消失」检查。

## U1 设置页只剩两个区

- **点哪里**：打开 DSH 设置（左下角齿轮/侧栏「设置」）→ 左侧列表找插件「集合石」→ 右侧看内容。
- **预期看到**：只有两个区：①「外部 CLI 连接」（Codex / CodeBuddy / Claude / DeepSeek Harness 等行，每行一个开关）；②「默认角色配置」（取经角色、一句说明、角色数量、「管理角色」按钮）。没有「高级设置 / 并行 / 调度 / 通道实例 / 配置文件路径」等。
- **算通过**：只有这两区、顺序一致、没有多余区块。
- **算失败**：出现第三区或任一被删项仍在（折叠起来也算）。
- **截图**：整页设置（含两个区标题）。

## U2 「管理角色」在设置页内展开、不跳走

- **点哪里**：设置页 → ②默认角色配置 → 点「管理角色」。
- **预期看到**：**当前设置页内**展开「全局角色管理」区域，列出角色名和每行的启用开关；页面不切换、不跳到会话页、**不打开右侧栏**。区域内有「返回/收起」可回设置主区。
- **算通过**：管理角色就在设置页里出现，地址栏/页面没变。
- **算失败**：页面跳转、右侧栏被打开、或打开的是会话角色面板。
- **截图**：点「管理角色」后整页（要同时看到设置页标题和管理角色列表）。

## U3 编辑一个全局角色并保存，重开还在

- **点哪里**：U2 的全局角色管理 → 点任一角色名进入编辑 → 改「角色设定」里任意一句 → 点保存（如出现二次确认再点确认）→ 收起面板 → 重新点「管理角色」进入看。
- **预期看到**：保存成功提示；重新打开后修改仍在。
- **算通过**：重开能看到刚才改的内容。
- **算失败**：保存没反应、重开丢失、或要求你手改配置文件。
- **截图**：保存后提示 + 重开后的编辑页。

## U4 新增一个全局角色

- **点哪里**：全局角色管理 → 点「新增角色」→ 名称填 `deck-hand`（英文，避免 ID 冲突）→ 角色设定随便写一句 → CLI 选 CodeBuddy（或任意可选项）→ 保存 → 收起再打开。
- **预期看到**：新增后列表里出现 `deck-hand`；重开还在。
- **算通过**：列表出现且重开仍在。
- **算失败**：点新增没反应、保存报错无法创建、或重开消失。
- **截图**：新增表单填写完 + 保存后列表。

## U5 删除一个全局角色

- **点哪里**：重新打开 U4 新增的 `deck-hand` 编辑页 → 点「删除角色」→ 出现确认提示 → 点「确认删除」→ 收起再打开列表。
- **预期看到**：删除前有二次确认（提示只删全局定义）；删除后列表里消失，重开也没有。
- **算通过**：二次确认出现、删除后消失、其他角色都还在。
- **算失败**：没有确认直接删、删错其他角色、或删除后仍在。
- **截图**：删除确认提示 + 删除后的列表。

## U6 角色编辑器：4 CLI + 模型有值 + 强度有值 + 刷新能力

- **点哪里**：任一角色编辑页，从上往下看字段。
- **预期看到**：字段依次为：名称、简称、**角色设定**（一个大文本框，不再同时有「描述」和「Prompt」）、CLI、模型、思考强度；头部有「刷新能力」。
- **必须检查**：
  1. CLI 下拉**只有 4 个**：DeepSeek Harness / Claude Code / Codex / CodeBuddy，**没有 ch-* 字样**；
  2. 打开即有模型值（如 CodeBuddy 下应能看到 glm-5.3-flash / hy3 / hy4free / kimi-k3.1-pro 等，来源标注「配置」；Codex 下 gpt-6-astra / gpt-6.1-sol）；选一个模型后**思考强度有值**（CodeBuddy 本机应显示 high「配置」）；
  3. 点「刷新能力」不报错，来源标注变化合理（动态/配置/静态/未知）；
  4. 选 DeepSeek Harness 时模型为空并置灰标「不支持」——这是预期，不算失败；
  5. 切换 CLI 后模型列表跟着变、切模型后强度跟着变。
- **算通过**：4 个 CLI、模型有值、强度有值、能刷新、来源标注可读、不支持时置灰。
- **算失败**：显示 ch-*、模型/强度为空且无「不支持」说明、刷新报错、同时存在「描述」「Prompt」、出现「通道」。
- **截图**：编辑器字段全貌 + CodeBuddy 模型下拉 + Codex 模型下拉 + 强度下拉（各 1 张）。
- **补充**：若模型/强度仍为空，请把编辑器截图 + 浏览器控制台 Network 里 `meetingstone/list` 返回的 `global.capabilities` 片段发给 Lead（这是本轮重点排查面）。

## U7 界面文案里没有「通道」

- **点哪里**：U1 设置页 + U6 编辑器 + 设置页全局管理。
- **预期看到**：没有「通道」「channel」这类字眼；用的是「CLI / 模型 / 思考强度」。
- **算通过**：你看到的地方都没有「通道」。
- **算失败**：任何用户可见文字出现「通道」。
- **截图**：编辑器整页作为「未出现」证据；发现则截那一处。

## U8 三色开关（灰 / 黄 / 绿，没有红色）

- **点哪里**：设置页 → 管理角色 → 看每行左侧开关颜色。
- **预期看到**：开关只有**开/关两态**，颜色只表达状态：灰=关闭或被依赖阻断；绿=开启且正常/额度未知；黄=开启且额度耗尽（本机大概率看不到黄，属正常）。
- **算通过**：颜色只有灰/黄/绿（没有红）；开关只有开/关两态；关闭的角色显示灰色。
- **算失败**：出现红色、或开关能点出第三种状态。
- **截图**：全局角色列表（至少 3 行）。
- **操作**：把任一角色开关关掉再打开，确认**即时生效**（不刷新页面），重开后状态保持。

## U9 【作废项消失】右侧栏 / 对话页头不再有角色入口

- **点哪里**：回到任一对话 → 看对话页头右侧 → 打开右侧栏看 tab 列表。
- **预期看到**：对话页头**没有**「角色」按钮；右侧栏**没有**「本对话角色」tab/面板；全局角色管理**只出现在设置页**。
- **算通过**：页头无角色按钮、右侧栏无角色面板、设置页只有一处全局管理。
- **算失败**：任一处仍出现角色入口/面板（这是 B3 回归，**阻塞发布**）。
- **截图**：对话页头 + 右侧栏。

## U10 设置页角色区有「返回」按钮

- **点哪里**：设置页 → 管理角色（展开后）→ 点区域内的「返回」。
- **预期看到**：回到集合石设置主区（两个区的页面），页面不跳转、不打开右侧栏、浏览器地址不变。
- **算通过**：点返回后回到设置主区，再点「管理角色」还能再进。
- **算失败**：点返回无反应、跳到别的页面、或没有返回按钮。
- **截图**：管理角色展开页（含返回按钮）+ 返回后的设置主区。
