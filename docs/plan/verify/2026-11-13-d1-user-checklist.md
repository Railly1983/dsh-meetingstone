# D1 用户配合清单（10 项，人眼确认）

> 用途：D1 真机验收里**只有人眼能确认**的部分。你不需要判断代码，也不改任何设置——只需要按步骤点、看、截图，然后把结果（通过/失败+截图）回给 Lead。
> 前置：DSH 已由 Lead 安装 0.1.0-alpha.4 并重启（当前正在运行，别关它）。
> 截图方法：`Win + Shift + S` 框选 → 粘贴到画图/微信保存；或 `Win + PrtSc`。每项截 1 张，文件名带编号（如 `U3-保存后.png`）。
> 提示：界面位置可能与我描述略有差异，按**名称**找即可；找不到入口 = 该项记「失败」并截图，不要自己改配置。

## U1 设置页只剩两个区

- **点哪里**：打开 DSH 设置（左下角齿轮/侧栏「设置」）→ 左侧列表找插件「集合石」→ 右侧看内容。
- **预期看到**：只有两个区：①「外部 CLI 连接」（Codex / CodeBuddy / Claude 三行，每行一个开关）；②「默认角色配置」（取经五人组、一句说明、角色数量、「管理角色」按钮）。没有「高级设置 / 并行 / 调度 / 通道实例 / 配置文件路径」等。
- **算通过**：只有这两区、顺序一致、没有多余区块。
- **算失败**：出现第三区或任一被删项仍在（折叠起来也算）。
- **截图**：整页设置（含两个区标题）。

## U2 「管理角色」在设置页内展开、不跳走

- **点哪里**：设置页 → ②默认角色配置 → 点「管理角色」。
- **预期看到**：**当前设置页内**展开「全局角色管理」区域（列出角色名）；页面不切换、不跳到会话页、**不打开右侧栏**。再点一次「收起」可关闭。
- **算通过**：管理角色就在设置页里出现，地址栏/页面没变。
- **算失败**：页面跳转、右侧栏被打开、或打开的是「本对话角色」会话面板。
- **截图**：点「管理角色」后整页（要同时看到设置页标题和管理角色列表）。

## U3 编辑一个全局角色并保存，重开还在

- **点哪里**：U2 的全局角色管理 → 点任一角色名进入编辑 → 改「角色设定」里任意一句 → 点保存 → 出现确认提示再点确认 → 收起面板 → 重新点「管理角色」进入看。
- **预期看到**：保存有二次确认；重新打开后修改仍在。
- **算通过**：重开能看到刚才改的内容。
- **算失败**：保存没反应、重开丢失、或要求你手改配置文件。
- **截图**：保存确认提示 + 重开后的编辑页。

## U4 新增一个全局角色

- **点哪里**：全局角色管理 → 点「新增角色」→ 名称填 `deck-hand`（英文，避免 ID 冲突）→ 角色设定随便写一句 → CLI 选 CodeBuddy（或任意可选项）→ 保存 → 确认 → 收起再打开。
- **预期看到**：新增后列表里出现 `deck-hand`；重开还在。
- **算通过**：列表出现且重开仍在。
- **算失败**：点新增没反应、保存报错无法创建、或重开消失。
- **截图**：新增表单填写完 + 保存后列表。

> 说明：若「模型/思考强度」显示「不支持/无可选」，**照常保存**即可，这是本机配置现状（U6 会解释），不影响新增。

## U5 删除一个全局角色

- **点哪里**：重新打开 U4 新增的 `deck-hand` 编辑页 → 点「删除角色」→ 出现确认提示 → 点「确认删除」→ 收起再打开列表。
- **预期看到**：删除前有二次确认，且提示大意是「只删全局默认，已有会话覆盖记录不会被改写」；删除后列表里消失，重开也没有。
- **算通过**：二次确认出现、删除后消失、其他角色都还在。
- **算失败**：没有确认直接删、删错其他角色、或删除后仍在。
- **截图**：删除确认提示 + 删除后的列表。

## U6 角色编辑器：只有「角色设定」+ CLI/模型/强度

- **点哪里**：任一角色编辑页，从上往下看字段。
- **预期看到**：字段依次为：名称、简称、**角色设定**（一个大文本框，不再同时有「描述」和「Prompt」两个框）、CLI、模型、思考强度。
- **联动测试**：把 CLI 从 CodeBuddy 切到 Codex（或反过来），看模型选项是否跟着变；再选模型，看思考强度选项是否跟着变。
- **预期**：模型/强度选项随上一级变化；本机 ACP（CodeBuddy）没声明模型/强度时显示「不支持/无可选」——**这是预期，不算失败**。
- **算通过**：只有一个「角色设定」框；切换 CLI 后模型列表跟着变。
- **算失败**：同时存在「描述」和「Prompt」两个可编辑框；切换 CLI 模型列表不动；出现「通道」字样。
- **截图**：编辑器字段全貌 + 切换 CLI 前后模型下拉各 1 张。

## U7 界面文案里没有「通道」

- **点哪里**：U1 设置页 + U6 编辑器 + 右侧栏「本对话角色」详情，各扫一眼。
- **预期看到**：没有「通道」「channel」这类字眼；用的是「CLI / 模型 / 思考强度 / 执行组合（如有）」。
- **算通过**：你看到的地方都没有「通道」。
- **算失败**：任何用户可见文字出现「通道」。
- **截图**：若发现，截那一处；没发现就截编辑器整页作为「未出现」证据。

## U8 右侧栏三色开关（灰 / 黄 / 绿，没有红色）

- **点哪里**：回到任一对话 → 点对话页头「角色」按钮 → 右侧栏「本对话角色」→ 看每行左侧开关颜色。
- **预期看到**：开关只有**开/关两态**，颜色只表达状态：灰=关闭或被依赖阻断；绿=开启且正常/额度未知；黄=开启且额度耗尽（本机大概率看不到黄，属正常）。
- **算通过**：颜色只有灰/黄/绿（没有红）；开关只有开/关两态。
- **算失败**：出现红色、或开关能点出第三种状态。
- **截图**：右侧栏角色列表（至少 3 行）。

## U9 会话覆盖只影响当前会话

- **准备**：新建两个对话：会话 A、会话 B（侧栏「新对话」两次）。
- **点哪里**：在会话 A 的右侧栏「本对话角色」里，把某个角色开关从开改成关（或改一个字段）→ 切到会话 B 看同一角色 → 再回设置页看全局角色。
- **预期看到**：只有会话 A 变了；会话 B 仍是默认；设置页全局角色不受影响。
- **算通过**：A 变、B 不变、全局不变。
- **算失败**：B 也跟着变，或全局被改动。
- **截图**：A 改后 + B 查看 + 设置页全局（3 张，文件名标 A/B/全局）。

## U10 没有重复面板、右侧栏没有「本会话/全局」切换

- **点哪里**：随便逛逛：设置页、对话页头「角色」按钮、右侧栏详情页。
- **预期看到**：全局角色管理**只出现在设置页**；右侧栏只有「本对话角色」会话面板，详情里**没有**「本会话 / 全局」切换按钮；没有第二个「角色」面板重复出现。
- **算通过**：全局管理仅 1 处、右侧栏无 scope 切换按钮。
- **算失败**：同一个角色面板出现两处、或右侧栏出现「本会话/全局」按钮。
- **截图**：右侧栏详情整页 + 设置页管理角色整页。
