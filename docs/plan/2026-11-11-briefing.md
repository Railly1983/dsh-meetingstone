## 三、并行多任务：最终形态

- **隔离方式**：每个写任务一棵独立 git 工作树（`src/worktree.js`，自建 literal-argv git）
  - 悟空裁决：**否决**复用 `ctx.worktrees.create()`——它会切走父会话 cwd，create→restore 无事务锁
- **并发上限**：同项目 2、全局 4；两级额度在首次异步操作前一起预占；**仅当前插件实例内计数**
- **失败关闭**：建树失败/非 git/路径冲突/超时 → 拒绝派单，**绝不退回主工作区**
- **不自动清理**：完成/失败/取消/卸载都保留工作树与分支，元数据免于 100 条/30 天淘汰
- **overlap 检测**：终态计算改动文件（含未跟踪/重命名/NUL 分隔），交叉回写 `overlapWarnings`；有上限（每对 50 文件/64KB/50 对）
- **文件布局隔离 ≠ 权限沙箱**：共享 git 元数据，cwd 不阻止越界写
