## 0. 原则

- **只做跨 CLI 协作**：角色配置、CLI/模型映射、派单、Worktree、上下文规范、缓存优化、结构化交接。
- **原生优先**：Goal / Agent Teams / Todo / Subagent / Background Jobs 一律复用，不自建替代模块。
- **先验证后开发**：交接文档要求的三项验证未完成前，不进入 UI 重构与功能开发。
- **八戒只做调度**：不参与具体编码/调研；由调度角色拆任务、控依赖、收口。
- **不修改正式代码**（本阶段仅计划与验证；验证通过后再开工）。

## 2. 分工汇总

- **沙僧**：V1、B0、B2、B3、C1、C3、D2（后端/契约/验证）
- **小白**：V2、V3、B1、C2、D1（UI/slot/设置页/真机）
- **八戒（调度）**：拆任务、依赖排序、状态跟踪、收口汇报；**不写代码**
- **Lead**：合并、测试、安装（Canary）、发布前复核

## 3. 执行顺序

1. 阶段 A 三项验证（并行）→ 产出结论
2. B0 调研 → 决定是否接入原生角色
3. B1 + B2（按 B0 结论）
4. C1–C3（可与 B 并行，但 C1 契约需先定）
5. D1–D3 验收发布
