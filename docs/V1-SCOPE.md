# 集合石 V1 范围冻结（Scope Freeze）

> 依据 Codex 2026-11-11 的下一阶段计划与产品判断：**集合石不管理整个 AI 团队，只让用户配置角色、准确派活、控制协作规则，以最低成本拿到可靠结果。**
> 本文件是 V1 的唯一范围基线；后续功能请求先对照本文件，不在范围内的一律进入 V1.1+ 候选，不进入 V1。

## 一、V1 只做四个工作包

### P0-1 配置与 UI（必须）
- 四个 CLI 连接检测与启停
- 全局角色库
- 对话顶部配置入口
- 对话级角色配置
- 全局 → 项目 → 对话配置继承
- 项目级配置继续用 `.meetingstone.json` 自动读取，不做项目管理 UI

### P0-2 派单与执行（必须）
- 四 CLI 稳定调用
- 按角色名称/简称派单
- 多 CLI 并行执行
- 任务等待（`meetingstone_wait`）、取消、结果回收
- 复用 DSH 原生权限、工作树、进程管理

### P0-3 协作与 Token 优化（核心亮点）
- 统一任务协议：任务名称 + 目标 + 范围 + 验收
- 统一结果协议：状态 + 结论 + 证据 + 完整报告路径
- 最小必要上下文传递（不传完整聊天历史、不让子 Agent 复述背景、给路径不重搜）
- 摘要优先、完整结果落盘、需要时再取全文
- 三项工具回执瘦身：`get_task` 默认摘要、`dispatch` 紧凑、`list_roles` 紧凑
- 默认免轮询、批量汇报
- 基础重复派单保护（进行中相同任务不重复创建）

### P0-4 稳定性与发布（必须）
- Windows 真实环境测试
- CLI 取消与进程清理
- 项目隔离与权限验证
- DSH 三个原生面板回归（Subagents / Background Tasks / Todo）
- GitHub 发布与 DSH 官方市场发布

## 二、V1 明确不做（写入开发规范）

- 不做画布/可视化工作流
- 不做独立任务管理系统
- 不做独立 Agent 会话管理
- 不做独立进程管理
- 不做 AI 自动调度 Agent
- 不做自动角色推荐/智能路由（用户直接指定；未指定用默认角色）
- 不做自动模型切换/额度接替
- 不做独立数据库/复杂队列
- 不做完整聊天历史同步
- 不做独立 Token 分析平台（复用 DSH Token Meter）
- 不做重复的项目管理与配置界面
- 不做 WorkBuddy 子智能体（暂缓，不影响四 CLI 主体发布）
- 不做自动冷却与重试、复杂失败分类系统（保留错误信息/退出码/基础分类）
- 不做完整 A/B 效率分析平台（用简单脚本和报告验证）
- 不做独立 Context Pack / Handoff 引擎（合并进任务协议）

## 三、配置简化

- 角色 = 名称 + 简称 + 描述 + CLI + 模型 + 思考强度；**只保留这一份定义**
- 不再维护通道模型映射、模型注册表、角色路由规则三套配置
- CLI 不支持某思考强度就显示"不支持"，不自行模拟
- 三级配置只保留逻辑，不做三套界面：全局（系统设置）、项目（`.meetingstone.json` 自动读取）、对话（顶部入口修改当前 Session）

## 四、产品存在的五个理由（只留这五件事）

1. 多 CLI 接入：四个平台稳定执行
2. 角色管理：用户定义自己的 AI 团队
3. 统一派单：一句自然语言指定角色执行
4. 高效协作：上下文最小化、结果结构化、减少重复工作与 Token 浪费
5. 安全可靠：权限、隔离、并发、取消、结果回收

## 五、已实现但不在 V1 范围的能力（处理方式）

| 能力 | 现状 | V1 处理 |
| --- | --- | --- |
| 自动角色路由（P1-B） | 已实现，默认关闭 | **默认关闭**；仅在调用方显式 `autoRoute:true` 时可用，文档不作为 V1 卖点 |
| 效率账本（P1-C） | 开发脚本 | 保留为开发工具（`npm run ledger`），不作为产品功能 |
| 真实 A/B 报告 | 开发报告 | 保留在 `docs/plan/`，不作为产品功能 |
| 失败分类（P1-A） | 已实现 | 保留基础分类与提示（符合"保留错误信息与基础分类"） |
| 进行中任务去重（P0-D） | 已实现 | 保留为"基础重复派单保护" |
| TaskSpec / ContextPack / Handoff | 已实现 | 作为**统一任务/结果协议**的一部分，不单独宣传 |
| Codex / WorkBuddy 跨宿主 POC | 文档与骨架 | 暂缓，归档到 `docs/cross-host/`，不进入 V1 发布 |
